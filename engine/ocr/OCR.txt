Sluka's screen reader (OCR)
===========================

The files in this folder read the text off a part of the screen, for a game
whose text no hook reads (the Screen tab of the game text menu).  They are
LunaTranslator's own, exactly as LunaTranslator 12.1.3.12 ships them
(LunaTranslator_x64.zip); nothing in them has been changed.

  CVUtils.dll             LunaTranslator's OCR (files\DLL64): it finds the
                          lines of text in a picture and reads them, with
  onnxruntime.dll         Microsoft's ONNX Runtime (files\DLL64), running
  model\det.onnx          PaddleOCR's PP-OCRv5 mobile model, which finds
  model\rec.onnx          the lines and reads them (Japanese, Chinese and
  model\dict.txt          English; files\ocrmodel)
  NativeUtils.dll         LunaTranslator's Windows helpers (files\DLL64):
                          Windows' own OCR, the box you drag over the
                          screen, and the requests to Google Lens and
                          its answers
  concrt140.dll, msvcp140.dll, msvcp140_1.dll, vcruntime140.dll,
  vcruntime140_1.dll      Microsoft's C++ runtime, which they need
                          (files\runtime3.13-64)

LunaTranslator can also read with the OCR inside Windows 11's Snipping Tool,
copied out of the Snipping Tool's folder.  Sluka does not: that OCR is a part
of Microsoft's Snipping Tool app, which Microsoft has not licensed for other
programs to copy out and run.  (Sluka Desktop 0.12.3 and before did; 0.12.4
takes away the copies they made, in data\ocr\SnippingTool.)

Google Lens is online: when it is chosen, each picture is sent to Google
(through Tor where Sluka is set to go online through it; never where Sluka
is set to stay offline), and Google's terms and privacy policy apply to it.
Sluka asks before Google Lens first reads; until a yes, an offline reader
reads instead.  "Auto" never chooses it.

ONNX Runtime, as Microsoft builds it, notes how it is used as trace events of
Windows' own, which Windows may send to Microsoft with its diagnostic data.
Sluka turns them off (ONNX Runtime's DisableTelemetryEvents) before its OCR
starts.

Sluka Desktop runs these from app\sluka_desktop\ocrd.py, a program of its
own, calling them the way LunaTranslator's own Python does.
