Sluka's engine for game text
============================

The files in this folder are LunaHook, the text hooker of LunaTranslator,
exactly as LunaTranslator 12.1.3.12 ships them (LunaTranslator_x64.zip).
Nothing in them has been changed; they are signed by their author.

  LunaHost64.dll          the host: told which game to read, it hears the
                          game's text  (LunaTranslator: files\LunaHook)
  LunaHook32.dll          put into a 32-bit or a 64-bit game, it finds the
  LunaHook64.dll          game's engine and catches its text  (files\LunaHook)
  LunaTmpFontLoader.dll   fonts for Unity games  (files\LunaHook)
  LunaSubprocess32.exe    put the hook into a 32-bit or a 64-bit game
  LunaSubprocess64.exe    ("dllinject")  (files)
  msvcp140.dll            Microsoft's C++ runtime, which LunaHost64.dll and
  vcruntime140.dll        LunaSubprocess64.exe need  (files\runtime3.13-64)
  vcruntime140_1.dll

Sluka Desktop runs them from app\sluka_desktop\hookd.py, a program of its own
that calls LunaHost64.dll the way LunaTranslator's own
src\LunaTranslator\textio\textsource\texthook.py does, and puts the hook
into a game the way LunaTranslator does (LunaSubprocess dllinject).

The ocr folder holds the screen's readers, for the Screen tab of the game
text menu and Sluka Vision: LunaTranslator's own OCR and its Windows
helpers, from the same LunaTranslator 12.1.3.12 (ocr\OCR.txt says which,
with their checksums).

LunaTranslator and LunaHook are by HIllya51 and their contributors.  They are
free software under the GNU General Public License, version 3: see
LICENSES\LICENSE.LunaTranslator.  LunaHook builds on Textractor, by Artikash
(LICENSES\LICENSE.Artikash.Textractor).  The licenses of everything
LunaTranslator is built from are in LICENSES, as LunaTranslator ships them;
NOTICES.txt, in Sluka Desktop's own folder, says which of them is in which
file here, and has what LICENSES lacks (its uchardet file is a web
page saved by mistake: ..\LICENSES\uchardet.txt is uchardet's licence).

Their source code, the very version these files are from, is in
source\LunaTranslator-12.1.3.12.zip (LunaHook: src\NativeImpl\LunaHook;
the injector: src\NativeImpl\LunaSubprocess), and on GitHub:

  https://github.com/HIllya51/LunaTranslator/tree/v12.1.3.12
  (commit 7772ec7bb186bd3773bb534dcbc8655a4a364150)

The C++ runtime files are Microsoft's, which may go with the programs that
need them (the Visual C++ Redistributable): NOTICES.txt, 3, in Sluka
Desktop's own folder, says on which terms.

A text hooker reaches into games, so antivirus programs sometimes take one
for a threat.  If Windows Security takes one of these files away, allow it in
its Protection history (or add this folder to its exclusions), and unpack
Sluka Desktop's zip again.  The files should be these (SHA-256):
